How to enable ADB Network Debugging on Android TV
  1. Enable Developer Mode: Go to Settings → System → About. Click Android TV OS build 7 times until it says "You are now a developer!".
  2. Enable Network Debugging: In Settings → System → Developer options, toggle USB debugging and Network debugging to ON.
  3. Enter TV IP: Input your TV's IP address above and click Connect / Pair TV.
  4. Allow Connection: When the prompt appears on TV, check "Always allow" and press OK.
